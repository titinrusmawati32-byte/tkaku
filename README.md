# Aplikasi Simulasi TKA & ANBK PUSMENDIK

Aplikasi web simulasi TKA & ANBK berbasis HTML, Tailwind CSS, dan Supabase.

## Struktur Project

- `index.html` — Letakkan file HTML lengkap aplikasi di sini.
- `.gitignore` — Daftar file yang diabaikan Git.

## Cara Menjalankan & Push ke GitHub

1. Pastikan file `index.html` lengkap sudah disimpan di folder ini.
2. Buka terminal di folder ini dan jalankan:

```bash
git init
git add .
git commit -m "Initial commit: Aplikasi Simulasi TKA & ANBK"
git branch -M main
git remote add origin https://github.com/<username-github>/<nama-repo>.git
git push -u origin main
```
